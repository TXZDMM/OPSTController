# Changelog

版本号语义：(大版本.小版本.bug修复)

## 0.8.1 — 当前版本（2026-10-06）

- 修复：程序库选择改为从「本机已安装程序」中选择（注册表 App Paths / Uninstall / HKCR Applications + 当前运行进程），名称经识别库归一化，与「谁更改了什么」提示口径一致，不再依赖手动输入
- 修复：识别库短关键词匹配加字符边界（如 "PPS" 不再误配 windowsapps 路径下的应用），长关键词优先匹配，消除错误识别
- 修复：滚轮交互重做——默认滚动整页；单击文本框/列表等小项后才滚动小项自身，点击其他区域交还页面
- 修复：退出时 "Failed to remove temporary directory: _MEI..." 警告弹窗——退出延迟等待安全软件完成临时目录扫描 + 退出前清理 + 启动后延迟重试清理残留
- 修复：程序列表显示名不再泄漏完整路径（识别未命中时退化为主程序名）

## 0.8.0 — 前版（2026-09-25 起）

- 分层防御 BH0–BH5：仅检测 → 自动恢复 → ACL 锁定 → System 完整性标签 → Untrusted 降权 → 进程冻结
- 进程打击器：对嫌疑进程降权 / 挂起 / 强终止，自动拉黑，累计 10 次进红名单（可在设置中关闭）
- 进程自保护：TI/SYSTEM 权限下普通用户无法通过任务管理器终止本进程
- 批量篡改检测（同一 ProgId 60 秒内 ≥8 个扩展名）与批量弹窗（单个队列 / 同时堆叠）
- 看门狗自恢复、审计日志导出（进程名/路径/命令行/数字签名/注册表变更）
- 关联扩展名同步检测（如 jpg↔jpeg）
- 基准文件导入、历史版本恢复（默认保留 5 个）

### 0.8.0 修订（2026-10-03，出版前整改）

- 界面：主工具栏移除独立的"历史版本"按钮，历史基准恢复并入"异常修复"工具面板
- 界面：异常修复面板重写为 19 项独立按钮（注册表锁定 / 篡改追踪 / 引擎 / 弹窗 / 进程打击 + 辅助），分区排版、可滚动、美化按钮
- 修复：异常修复-解除注册表锁定改为解除全部受保护扩展名并清除锁定计数（原仅解除追踪器当前标记的键）
- 修复：异常修复-重置持续篡改追踪器在清空前先解除登记的注册表锁定，避免 Deny ACL 残留无法自动解锁
- 修复：异常修复-清除进程黑名单改为清空真实内存状态并按正确格式落盘（原写入空列表且引用不存在的属性，导致内存黑名单未清除）
- 体验：异常修复-一键全部修复不再重复弹出多个确认框
- 修复：无效关联（命令缺失）不再计入持续/批量篡改判定，避免级联误锁注册表键
- 安全：移除源码中硬编码的个人绝对路径；NSudo 查找改为 `runtime/` 相对解析 + 环境变量 `OPST_NSudo_PATH`
- 安全：移除内置第三方网盘下载链接与口令，改为跳转项目主页查看基准说明
- 发布：新增本 CHANGELOG、exe 版本资源（文件版本/产品信息）、`停止OPSTcontroller.bat`、NSudo 许可随包分发；发布包清理调试产物与用户数据，首次运行自动生成空白 userdata 模板

### 0.8.0 修订（2026-10-05/06，发行打磨）

- 界面：扩展名页移除「保护及说明」「基准操作」独立卡，说明并入状态页「保护状态」卡，基准操作分流至状态页底部与设置「基准」卡
- 功能：扩展名页「统计信息」下方新增「单扩展名锁定」板块——读取/锁定单个扩展名默认打开方式、锁定列表、解锁，配置写入文件持久化
- 界面：状态栏下方常用操作按钮自动换行适配窗口缩放；「进程自我保护及启用」整合进「保护状态」分类并移除括号备注
- 界面：异常修复按钮统一深色配色；点击任一修复按钮后自动跳转回状态页保护输出窗口
- 界面：设置页新增小尺寸适配——窗口缩小时按钮文字改为「过小」，继续缩小则自动隐藏，杜绝裁切
- 界面：状态页保护输出日志区域拉长拉高（16 行 → 26 行）
- 功能：程序白名单/黑名单识别对象为进程名，添加方式支持「从程序库选择」（内置软件库 + 当前运行进程），新增独立「进程黑名单」卡
- 体验：设置修改默认自动保存，移除「保存设置」「放弃修改」按钮
- 识别：内置软件名称识别库覆盖近 500 家主流常用软件
- 修复：窗口缩放触发的流式布局死循环（主线程长时间无响应）——预建行容器 + 重入保护
- 修复：监控统计遍历与锁定巡检并发修改字典导致的 `RuntimeError: dictionary changed size during iteration`——迭代快照化
