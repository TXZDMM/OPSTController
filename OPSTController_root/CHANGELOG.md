# Changelog

版本号语义：(大版本.小版本.bug修复)

## 0.8.1 — 当前版本

- 修复：程序库选择改为从「本机已安装程序」中选择（注册表 App Paths / Uninstall / HKCR Applications + 当前运行进程），名称经识别库归一化，与「谁更改了什么」提示口径一致，不再依赖手动输入
- 修复：识别库短关键词匹配加字符边界（如 "PPS" 不再误配 windowsapps 路径下的应用），长关键词优先匹配，消除错误识别
- 修复：滚轮交互重做——默认滚动整页；单击文本框/列表等小项后才滚动小项自身，点击其他区域交还页面
- 修复：退出时 "Failed to remove temporary directory: _MEI..." 警告弹窗——退出延迟等待安全软件完成临时目录扫描 + 退出前多根清理 + 启动后 30s/90s 延迟重试清理残留
- 修复：程序列表显示名不再泄漏完整路径（识别未命中时退化为主程序名）
- 修复：`--stop` 完全退出失效——自我保护实例（TI/SYSTEM）无法被普通令牌终止的根因修复：新增退出信号看门狗线程（不依赖 UI 主循环）+ `--stop-admin` 管理员强杀路径（SeDebug+TerminateProcess）；修复 taskkill 误杀 `--stop` 自身导致提权流程中断的问题
- 修复：开机自启旧值（无 `-m` 最小化参数，旧版本写入）不再被识别为已设置——启动时自动升级为带 `-m` 的启动项，开机后台最小化常驻
- 修复：开机自启读写增加 reg 命令兜底（部分受限环境 winreg 打开被拒时仍可写入/移除）
- 修复：日志轮转改用安全截断式轮转（标准 RotatingFileHandler 在打包 + 多进程共用日志环境下会导致启动卡死、日志不落盘）——protector.log 上限 2MB 自动备份 3 份
- 修复：一键全部修复的确认框/完成提示统一为 20 项（与按钮文案一致，原提示残留"19 项"）
- 界面：黑/白名单「从程序库选择」按钮改名「从本机程序选择」，与"程序库仅用于识别显示"的定位区分，避免混淆
- 修复：`--stop` 退出路径显式解锁注册表 Deny ACL——原实现 stop() 仅置位事件，监控线程可能仍在 sleep 时 os._exit 抢先，导致注册表锁定残留、下次启动扩展名被锁死无法更改默认应用（压力测试实测 40/40 注入被拒）
- 功能：单扩展名锁定升级为「强锁定」——锁定目标优先于基准（删除 UserChoice 使旧 Hash 失效 + 强制 HKCR 默认值=锁定应用，无需系统 Hash 算法）；锁定扩展名被篡改时静默强制恢复且不弹窗；基准重建后自动重新落实锁定；列表实时显示一致性状态（✓ 一致 / ✗ 当前被改 / ○ 待落实）；新增「解锁全部」「刷新状态」按钮与重复锁定提示；解锁时自动同步基准
- 功能：新增「防护记录」大菜单——统计概览（总记录 / 今日 / 自动阻止 / 用户同意 / Top 扩展名 / Top 篡改者）+ 可搜索记录表格（扩展名 / 篡改者过滤）+ 单击查看详情 + 双击对比该扩展名当前 7 项注册表状态 + 清空 / 导出
- 功能：新增「系统诊断」大菜单——一键体检报告（权限与管理员令牌、提权链、自我保护、基准状态、单扩展名锁定一致性、开机自启、日志轮转、_MEI 清理、识别库条目、防护记录规模），支持复制与保存为 txt
- 功能：新增「配置与备份」大菜单——一键备份/恢复全部配置（基准/锁定/黑白名单/识别库/防护记录/日志打包为 zip）、导出/导入黑白名单与锁定配置（迁移用）、实时配置概览（基准规模/锁定数/名单数/识别库条目/运行模式/权限/审计级别）
- 修复：锁定恢复补充 HKCU\Software\Classes 用户级覆盖修正与残留 shell 清理（普通令牌程序篡改经虚拟化写入用户级覆盖，仅写 HKCR 会被遮蔽导致恢复无效）
- 修复：update_extension 日志区分「用户单次同意 / 锁定同步 / 锁定解锁 / 锁定重落实」，消除误导文案
- 修复：锁定面板可见性——更新锁定目标提示不再被"已锁定"文案立即覆盖、无选中解锁给出反馈、基准同步失败记 warn 日志并提示、列表查询失败可见、OpenWithProgids 写入失败记日志

## 0.8.0 — 前版

- 分层防御 BH0–BH5：仅检测 → 自动恢复 → ACL 锁定 → System 完整性标签 → Untrusted 降权 → 进程冻结
- 进程打击器：对嫌疑进程降权 / 挂起 / 强终止，自动拉黑，累计 10 次进红名单（可在设置中关闭）
- 进程自保护：TI/SYSTEM 权限下普通用户无法通过任务管理器终止本进程
- 批量篡改检测（同一 ProgId 60 秒内 ≥8 个扩展名）与批量弹窗（单个队列 / 同时堆叠）
- 看门狗自恢复、审计日志导出（进程名/路径/命令行/数字签名/注册表变更）
- 关联扩展名同步检测（如 jpg↔jpeg）
- 基准文件导入、历史版本恢复（默认保留 5 个）

### 0.8.0 修订（出版前整改）

- 界面：主工具栏移除独立的"历史版本"按钮，历史基准恢复并入"异常修复"工具面板
- 界面：异常修复面板重写为 19 项独立按钮（注册表锁定 / 篡改追踪 / 引擎 / 弹窗 / 进程打击 + 辅助），分区排版、可滚动、美化按钮
- 修复：异常修复-解除注册表锁定改为解除全部受保护扩展名并清除锁定计数（原仅解除追踪器当前标记的键）
- 修复：异常修复-重置持续篡改追踪器在清空前先解除登记的注册表锁定，避免 Deny ACL 残留无法自动解锁
- 修复：异常修复-清除进程黑名单改为清空真实内存状态并按正确格式落盘（原写入空列表且引用不存在的属性，导致内存黑名单未清除）
- 体验：异常修复-一键全部修复不再重复弹出多个确认框
- 修复：无效关联（命令缺失）不再计入持续/批量篡改判定，避免级联误锁注册表键
- 安全：移除源码中硬编码的个人绝对路径；NSudo 查找改为 `runtime/` 相对解析 + 环境变量 `OPST_NSudo_PATH`
- 安全：移除内置第三方网盘下载链接与口令，改为跳转项目主页查看基准说明
- 发布：新增本 CHANGELOG、exe 版本资源（文件版本/产品信息）、`停止OPSTcontroller.bat`、NSudo 许可随包分发；发布包清理调试产物与用户数据，首次运行自动生成空白 userdata 模板

### 0.8.0 修订（UI 改版 + 自我保护修复）

- 界面：主窗口重做为 **Win11 设置深色风格**（左侧导航 + 右侧内容页，深色卡片、Win11 风格按钮），新增状态/扩展名/工具/日志/设置 5 个页面；原异常修复面板与设置对话框内嵌为主窗口页面
- 修复：**进程自我保护失效**（捆绑的 NSudo 9.0 预览版 `-U:T` 只提供受限 SYSTEM 令牌、0 特权）→ `protect_self_process()` 改分级降级：特权可用写完整 DACL+SACL+完整性标签；特权被移除时仅写 DACL（拒绝 Users/管理员终止/挂起），不再整体失败；`_enable_privilege()` 现在按 `ERROR_NOT_ALL_ASSIGNED` 正确判断启用结果
- 修复：**NSudo 9.0 预览版替换为 8.2 稳定版**（`Win32/NSudoLC.exe`，实测 `-U:T` 提供真正的 TrustedInstaller 令牌 + System 完整性），提权路径恢复依赖真实 TI 权限
- 界面：自我保护状态（完整保护/降级保护/未生效）与真实权限 SID 显示在状态页
- 发布：重新构建 exe（9.15MB）、重打发行包，发布目录 userdata 保持空白模板（仅 program_names.json）
