# test/ 目录说明

本目录存放开发期测试工具，**不随正式发布包分发**。

## LHA_Tamper.exe

- 用途：本地开发测试用"文件关联篡改模拟器"，用于验证本程序的持续篡改/批量篡改防护逻辑是否按预期触发。
- 注意：
  - 该文件为第三方/内部测试工具，**无数字签名、无版本信息，许可证来源未确认**。在向他人分发本仓库或发布版本前，请先确认其来源与许可，或将其从仓库中移除。
  - 该工具会修改系统文件关联设置，请仅在测试机/虚拟机中使用，并提前备份注册表或准备恢复方案。
- 验证方式：运行本程序并开启保护后，使用 LHA_Tamper.exe 对若干扩展名进行关联修改，观察右下角通知、注册表锁定与进程打击日志（`userdata/protector.log`）。
